    اختبر نفسك .. كيف يراك الناس؟

    ٢٥ أكتوبر ٢٠٠٩ حياتناقراءة في ٥ د

    جاوب على هذه الأسئلة البسيطة بصدق، فقد طبق هذا الاختبار في الغرب لمعرفة وجهة نظر الناس في بعضهم البعض.

    1. متى تشعر بالنشاط الكامل؟

    (a) في الصباح. (نقطتان)

    (b) خلال فترة الظهر وبداية فترة المساء. (4 نقاط)

    (c) في فترة متأخرة من الليل. (6 نقاط)

    2. أنت عادة تمشي؟

    (a) بسرعة, مع خطوات طويلة. (6 نقاط)

    (b) على نحو سريع, مع خطوات سريعة وقصيرة. (4 نقاط)

    (c) رأسك مرتفع, ترى العالم إلى الامام. (7 نقاط)

    (d) بطيء ورأسك منخفض. ( نقطتان)

    (e) بطيء جداً. ( نقطة واحدة )

    3. عندما تتحدث إلى الناس؟

    (a) تقف ذراعك مثني حولك. (4 نقاط)

    (b) يداك متصافحتان. ( نقطتان)

    (c) تكون أحدى أو كلتا اليدان حول خصرك. ( 5 نقاط )

    (d) تلمس أو تدفع من تتحدث إليه. ( 7 نقاط )

    (e) تلعب بأذنك، أو تلعب بذقنك ،أو تلعب بشعرك. ( 6 نقاط)

    4. عندما تكون مرتاحاً تجلس و....

    (a) ركبتك منحنية. ( 4 نقاط )

    (b) رجلاك متقاطعتان. ( 6 نقاط )

    (c) رجلك تكون ممدودة بشكل مستقيم. ( نقطتان )

    (d) أحدى رجليك ملتفة أو مطوية تحتك. ( نقطة واحدة )

    5. عندما تسمع ما هو طريف..

    (a) تضحك ضحكة كبيرة ( 6 نقاط )

    (b) تضحك لكن ليس بصوت عال ( 4 نقاط )

    (c) تضحك بينك وبين نفسك بصوت خافت ( 3 نقاط )

    (d) تبتسم ابتسامة خجولة ( 5 نقاط )

    6. عندما تذهب إلى حفلة أو اجتماع كبير فأنت ...

    (a) تدخل بقوة حتى ينتبه لك الآخرين ( 6 نقاط )

    (b) تدخل بهدوء وتبحث عن أي شخص تعرفه ( 4 نقاط )

    (c) تدخل بهدوء وتحاول ألا يلاحظك الحاضرين ( نقطتان )

    7. أنت متعب من العمل وتبذل كل جهدك، إذا أزعجك أو قاطعك احدهم فهل...

    (a) ترحب بوقت للراحةمعه ( 6 نقاط )

    (b) تشعر بغضب كبير ( نقطتان )

    (c) يكون شعورك مختلط بين الحالتين ( 4 نقاط )

    8. أي من الألوان التالية تفضل أكثر

    (a) الأحمر والبرتقالي ( 6 نقاط )

    (b) الأسود ( 7 نقاط )

    (c) الأصفر او الأزرق الفاتح ( 5 نقاط )

    (d) الأخضر ( 4 نقاط )

    (e) الأزرق القاتم او البنفسج ( 3 نقاط )

    (f) الأبيض ( نقطتان )

    (g) البني أو الرمادي ( نقطة واحدة )

    9. عندما تكون في السرير, قبل النوم تستلقي وأنت...

    (a) ممد على ظهرك ( 7 نقاط )

    (b) تستلقي على وجهك وبطنك ( 6 نقاط )

    (c) تستلقي على جانب واحد منطوي ( 4 نقاط )

    (d) تضع إحدى يديك تحت رأسك ( نقطتان )

    (e) تستلقي ورأسك مغطى ( نقطة واحدة )

    10. احياناً تحلم انك ....

    (a) تقع ( 4 نقاط)

    (b) تعارك أو تقاوم ( نقطتان )

    (c) تبحث عن شخص او عن شيء ( 3 نقاط )

    (d) تطير أو تعوم ( 5 نقاط )

    (e) غالباً لا تحلم ( 6 نقاط )

    (f) أحلامك دائماً سعيدة ( نقطة واحدة )

    احسب النقاط التي جمعتها

    النتائج:

    60 نقطة أو أكثر:

    يرونك كانسان متباهي،تريد جذب الانتباه، فأنت شخص مسيطر بشكل فظيع ربما الآخرين معجبين بك ويتمنون أن يكونوا مثلك ولكنهم لا يثقون بك, يترددون في علاقاتهم بك.

    النقاط ما بين 51 إلى 60:

    يرونك كشخصيه مثيرة للاهتمام، متقلبة ومندفعة أنت قائد أو مسيطر بالفطرة تتخذ قراراتك بسرعة. جريء و مغامر، تحب أن تستغل الفرص. ويستمتع الآخرين برفقتك.

    النقاط من 41 إلى 50:

    يرونك شخصية نشيطة، حيوية، ممتعة، مسلية، عملية، ودائماً ممتع تجذب الانتباه، شخص متوازن،لا تزعج الآخرين. رفقتك تبهجهم وتسعدهم.

    النقاط من 31 إلى 40:

    يرونك إنسان حساس،حذر،عملي، موهوب، متواضع، لست من النوع الذي يقيم صداقات بسرعة أو بسهولة، لكنك شديد الوفاء وتتوقع الوفاء بالمثل، الذين يعرفونك عز المعرفة يدركون انه من الصعب هز ثقتك بأصدقائك.

    النقاط من 21 إلى 30:

    أصدقائك يرونك كشخص مجتهد وصعب الإرضاء فهم يرونك حذر, وشديد العناية, بطيء وثابت التهادي أو وقع الأقدام فقد يدهشهم إذا قمت بعمل مندفع أو قمت بعمل مثير في لحظة فهم يتوقعون منك انك تمعن النظر بدقه في كل زاوية, وبعدها فأنت عادة ما تقرر ضده أو ترفضه فهم يعتقدون ذلك بسبب شخصيتك المتأنية.

    تحت 21 نقطة:

    الناس يرونك شخص خجول, متوتر, ومتردد فأنت تحتاج إلى اهتمام, شخص دائماً يعتمد على الآخرين في اتخاذ قراراته فأنت لا تحب الاختلاط مع اي شخص أو التدخل في أي شيء. أنت ترى المشكلات التي هي بالأصل غير موجودة.
